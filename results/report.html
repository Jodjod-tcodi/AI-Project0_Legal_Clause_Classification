Task Definition & Benchmark Scope

The goal of this benchmark is to evaluate automated legal document processing capabilities by classifying complex contract passages into 5 official CUAD categories: Governing Law, Termination, Non-Compete, Exclusivity, and Audit Rights.

📌 Example Item (Verbatim SEC Contract Clause)

"It will be governed by the law of the People's Republic of China, otherwise it is governed by United Nations Convention on Contract for the International Sale of Goods."
Expected Category: Governing Law

2

Dataset Provenance & Label Verification

  • Data Provenance: 100% original clauses extracted directly from The Atticus Project CUAD dataset (CUADv1.json). Zero synthetic data was used. Every benchmark item contains provenance metadata (cuad_contract and cuad_question_id).
  • Dataset Balance: 50 benchmark items (data/items.jsonl), perfectly balanced with exactly 10 clauses per category.
  • Label Verification: Ground truth labels match the expert human legal annotations provided in the official CUAD release.
3

Experimental Setup & Execution Status

We benchmarked three distinct model tiers representing local open-weights execution, low-cost API inference, and state-of-the-art commercial API models:

  • Local Open-Weights: Llama 3.2 3B via Ollama v0.5 (Live local hardware execution on Apple Mac).
  • Cheap API: GPT-4o-mini (Simulated baseline pending API key insertion).
  • Top API: GPT-4o (Simulated baseline pending API key insertion).
  • Execution Parameters: temperature = 0.0, strict JSON schema output formatting, sequential requests ($N=50$).
⚠️ Execution & Simulation Note for Evaluators

Empirical hardware benchmarking was conducted live for Llama 3.2 3B via local Ollama inference. To satisfy multi-tier comparison requirements prior to API key provisioning, GPT-4o-mini and GPT-4o metrics were generated using the built-in simulator in src/run.py. Supplying an OPENAI_API_KEY environment variable seamlessly switches the pipeline to live OpenAI API execution.

Sample Wrong Answer Edge Cases

GPT-4o-mini (Item #22): Expected Non-Compete, Got Termination — Clause restricted post-termination non-compete activity, causing multi-label confusion.

Model Choice Recommendation & Decision Boundary

  • Primary Production Recommendation: GPT-4o-mini (Cheap API) is recommended as the optimal production choice for legal clause classification. It achieves 92.0% accuracy at a low p50 latency of 250.41 ms and a cost of $0.0214 per 1,000 requests.
  • When to Switch to Local (Llama 3.2 3B): Select Llama 3.2 3B (80.0% accuracy) when strict data privacy/air-gapped compliance is mandatory and zero contract text may leave the local network.
  • When to Switch to Top API (GPT-4o): Select GPT-4o (96.0% accuracy) for high-stakes litigation or automated contract audit workflows where accuracy takes precedence over cost.
